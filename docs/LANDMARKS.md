# Landmark target list

Hand-scripted parametric Blender models (ADR-003 exempts landmarks from the shell+kit path). Each entry is produced by `blender/landmarks/<script>.py`, keyed to real footprint BIN(s) from the OTI footprints dataset, with published dimensions cited in the script docstring. Per-landmark fidelity statements are aggregated from `blender_out/landmarks/catalog/*.json` into `FIDELITY_REPORT.md` §Landmarks.
